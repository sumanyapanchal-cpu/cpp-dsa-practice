# C++ DSA Practice

A personal repository documenting my journey of learning and practising **Data Structures and Algorithms (DSA) using C++**.

This repository includes implementations of various DSA concepts, coding exercises, problem-solving approaches, and optimised solutions as part of my consistent practice.

## Learning Resource

**Apna College – Complete C++ DSA Course** by Shradha Khapra Ma'am.

[Watch the Playlist](https://www.youtube.com/playlist?list=PLfqMhTWNBTe137I_EPQd34TsgV6IO55pt)

## Topics Covered

- **C++ Fundamentals:** Variables, Data Types, Operators, Loops, Functions and Pointers.
- **Arrays & Vectors:** Array Manipulation, Subarrays, Kadane's Algorithm and Common Array Problems.
- **Complexity Analysis:** Time and Space Complexity, Big O Notation.
- **Searching:** Linear Search, Binary Search and Binary Search on Answer.
- **Sorting:** Bubble Sort, Selection Sort, Insertion Sort, Merge Sort and other Sorting Techniques.
- **C++ STL:** Vectors, Pairs, Algorithms and Standard Template Library.
- **Strings:** String Manipulation, Character Arrays and String-Based Problems.
- **Mathematics:** Number Theory, GCD, Prime Numbers and Bit Manipulation.
- **2D Arrays:** Matrix Traversal, Searching and Matrix-Based Problems.
- **Hashing:** Hash Maps, Frequency Counting and Prefix Sums.
- **Recursion & Backtracking:** Recursive Algorithms, Subsets, Permutations, N-Queens, Sudoku Solver and Rat in a Maze.
